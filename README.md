# Coleção de Formação Docente sobre o Moodle

**Do "como fazer" ao "por que fazer"**

Uma proposta de formação docente para o uso pedagógico do Moodle
no contexto da Educação a Distância da UFU.

---

---

## 🎯 Objetivo

Desenvolver uma proposta de formação docente para o uso pedagógico
do Moodle, articulando conhecimentos técnicos, situações-problema,
fundamentos pedagógicos, experimentação e reflexão.
